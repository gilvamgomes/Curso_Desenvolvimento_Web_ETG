# 💻 Desenvolvedor Web (EAD)

Este repositório foi criado para armazenar os exercícios, projetos e avaliações desenvolvidos ao longo do **Curso de Qualificação Profissional em Desenvolvedor Web** (200h).

---

## 📚 Módulos do Curso

| Módulo | Carga Horária |
| :--- | :---: |
| **01. Lógica, Git & GitHub** | 40h |
| **02. HTML5 & CSS3** | 60h |
| **03. JavaScript** | 40h |
| **04. Vue.js** | 40h |
| **05. Back-end** | 40h |

---

## 🛠️ Tecnologias e Ferramentas

* **Front-end:** HTML5, CSS3, JavaScript, Vue.js
* **Back-end:** Node.js, Express.js
* **Banco de Dados:** MongoDB (MongoDB Compass)
* **Ferramentas:** Git, GitHub, VS Code, Docker Desktop, Insomnia
