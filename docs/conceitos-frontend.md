O que é Front-end?
É a parte visual e interativa de um site ou aplicativo. É a interface com a qual o usuário interage diretamente no seu navegador ou dispositivo. 

Para que serve?
- Exibe as informações e telas para o usuário.
- Garante uma navegação intuitiva e agradável.
- Captura as ações do usuário (clique, digitação) e reage a elas.

Tem como principais tecnologias o HTML e CSS.
