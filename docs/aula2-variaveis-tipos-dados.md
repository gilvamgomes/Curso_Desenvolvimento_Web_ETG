Vimos o conteúdo de variáveis e tipos de dados na aula 2. 

O que é variável?
É um espaço reservado na memória do computador destinado a armazenar uma informação que pode ser alterada durante a execução do programa.

Tipos de dados no contexto da programação

Primitivos:
- Inteiro (int): Números inteiros, sem casas decimais.
Ex.: -10, 0, 42.

- Real (float, double): Números com casas decimais.
Ex.: 3.24, -0.5, 150.50

- Texto (string, char): Sequência de caracteres (letras, símbolos e números lidos como texto).
Ex.: "Olá!", "123", "A"

- Lógico ou Booleano (bool): Representa apenas dois estados possíveis, sendo verdadeiro ou falso.
Ex.: Verdadeiro / Falso ou true / false

Compostos:
- Vetores (arrays): Coleções ordenadas de elementos do mesmo tipo. É uma única linha com várias colunas. Tem como regra que todos os elementos DEVEM ser do mesmo tipo.
Ex.: Notas de alunos

- Matrizes: Estruturas bidimensionais, como uma tabela com linhas e colunas. Também DEVEM ser do mesmo tipo. 
Ex.: Tabuleiro de xadrez.

- Registros (structs): Estruturas que agrupam variáveis de tipos diferentes sob um mesmo nome.
Ex.: Um registro (Aluno) contendo: 
    Nome (texto)
    Idade (inteiro)
    Média (real)
